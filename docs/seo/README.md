В рамках практической работы по SEO я полностью подготовила главную страницу сайта к проверке. В коде index.html выставила правильный язык страницы (ru), добавила нормальное описание в тег description и проверила, чтобы заголовки шли по порядку без пропусков уровней.
В папку static закинула файлы robots.txt и sitemap.xml. В первом закрыла от поисковых роботов наш бэкенд, а во втором прописала прямую ссылку на главную страницу, чтобы сайт правильно индексировался.
На самом бэкенде во Flask настроила роуты для этих файлов, а также добавила специальное правило, которое автоматически вешает заголовок X-Robots-Tag со значением noindex, nofollow на все запросы к API. Это защитит наши сырые данные из базы данных от попадания в поисковики.
В самом конце запустила тест Lighthouse в режиме инкогнито на компьютере. Сайт набрал отличный результат в 92 балла. Все скриншоты тестов до и после, как и просили, лежат в папке docs/seo/.
